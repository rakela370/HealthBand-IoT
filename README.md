# HealthBand

HealthBand je simulirani wearable IoT uređaj razvijen u okviru diplomskog rada.

Simulator uređaja implementira se kao modularna Python aplikacija na Windows računaru i povezuje sa AWS cloud infrastrukturom.

## Glavne komponente

- Python HealthBand device simulator
- AWS IoT Core
- MQTT preko TLS-a
- X.509 autentikacija
- AWS IoT Device Shadow
- AWS IoT Jobs
- Amazon DynamoDB
- Amazon S3
- FastAPI backend
- HTML/CSS/JavaScript frontend
- SQLite offline storage
- pytest testovi

## Važno

Svi zdravstveni i aktivnosti podaci u projektu su simulirani.

HealthBand nije medicinski uređaj.
